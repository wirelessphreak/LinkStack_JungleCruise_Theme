# Jungle Tiki

A vintage tiki theme for LinkStack: lantern-lit jungle night photo, Limelight title, Cormorant Garamond body, burnt parchment buttons.

- Theme Name: Jungle Tiki
- Theme Version: 1.0
- Theme Date: 2026-10-15
- Theme License: GPLv3

### Used assets
- Fonts: Limelight and Cormorant Garamond (SIL Open Font License), loaded from Google Fonts
- Background: the owner's own photo, embedded in skeleton-auto.css
- Built using https://github.com/dhg/Skeleton (MIT)
